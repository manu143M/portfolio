# 🚀 Manu.dev - Personal Portfolio

Welcome to the repository for my personal developer portfolio! This is a fully custom, mobile-responsive website built from the ground up to showcase my skills as a full-stack developer.

🔗 **Live Demo:** [https://manu143M.github.io/portfolio](https://manu143M.github.io/portfolio)

![Portfolio Preview](pics1/main.jpeg) ## ✨ Features

* **Custom Animations:** Engineered dynamic "anti-gravity" floating effects and glassmorphism UI elements using pure CSS.
* **Interactive Project Galleries:** Custom-built JavaScript sliding side-panels to display project images and legal documentation without leaving the main page.
* **Serverless Contact Form:** Built a custom JavaScript `fetch` integration that bypasses CORS restrictions to securely send client messages directly to a Google Sheets database.
* **100% Mobile Responsive:** Fluid grid layouts and CSS media queries ensure the site looks like a premium native app on phones and tablets.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Vanilla JavaScript
* **Backend Integration:** Google Apps Script (Serverless database connection)
* **Design:** Custom UI/UX, BoxIcons
* **Hosting:** GitHub Pages
